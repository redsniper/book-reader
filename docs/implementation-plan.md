- 偏差记录：
  - 设计阶段的“段间距”设置在实现中移除，避免 Compose 渲染与 StaticLayout 分页测量不一致；需求未要求该项。
  - 封面文件名统一为 `cover.img`（按字节保存，按内容解码），而非设计初稿的 `cover.jpg`。
  - EPUB 内部多锚点目录合并为 spine 文档级章节（设计已列为 v1 限制）。
  - **会话策略变更（用户确认）**：原 BB-15 预期“后台返回仍停留在隐藏会话”，现改为应用进入后台立即锁定；返回隐藏书阅读页时显示锁定提示，隐藏书架退回普通书架。`HiddenShelfSession` 仍只存进程内存，符合安全红线。
  - 为修复桌面图标返回时叠加新书架 Activity 的问题，`MainActivity` 使用 `singleTop`，与 NavHost 单 Activity 架构一致。
  - 分页缓存采用书籍目录下的二进制文件而非 Room 表：页索引是派生数据，文件缓存避免数据库 schema 迁移，且能随书籍目录级联删除。
  - 阅读视口改为与系统栏 inset 解耦：全屏只避让显示挖孔，分屏/自由窗口才使用 `safeDrawing`；
    分页器与正文 `Text` 共用同一 `LocalDensity` 解析的字号/行高 px（含 Android 14+ 非线性字体
    缩放）。这修复了 h=2589px / h=2733px 两套索引与大字号半屏问题。
  - 设置面板固定全展开并固定预览卡片高度：Material3 底部弹层会随内容高度变化重算
    Expanded/PartiallyExpanded 锚点，预览字号一变就把面板塌回半屏，因此不能靠“内容自适应”。
  - 字号/行距/边距滑块改为连续值，落地时由 `ReaderSettings.sanitized()` 取整；设计文档中的
    “步长 1”约束仍然成立，只是从“拖动时强制吸附刻度”改为“松手后按步长落地”，以换取跟手性。
  - 打开非默认字号书籍时不再先按默认字号排一次：`Paginating` 携带真实设置，ViewModel 丢弃
    Loading 期视口，ReaderScreen 在真实字号帧只触发一次分页；避免两次排版之间用页起点衔接
    造成进度前跳。
  - **下拉触发时机变更（用户确认）**：原实现越过 140dp 阈值立即弹密码框；M16 改为进入
    `ARMED` 后松手触发。这样才与“松开进入隐藏书架”文案一致，也避免弹框打断拖动。
  - **下拉阈值与提示时机再次变更（用户确认，2026-11-10）**：M16 的“阈值前显示进度环与继续下拉文案”
    会让隐藏入口在很短的拖动下就暴露。按用户要求改为：阈值 = 整窗高度 2/3；阈值前只保留跟手位移
    （上限 120dp），不显示圆环/文案/震动；越过阈值才淡入“松开进入”并轻震。固定 dp 阈值不再适用。
  - **下拉阈值再次变更（用户确认，2026-11-14）**：进入隐藏书架的阈值由整窗高度 2/3 屏下调为 1/2 屏；
    静默段、松手触发、单次轻震、120dp 位移上限、回弹与进入转场均保持不变。
  - 下拉动画不引入新依赖：位移用布局阶段 `Modifier.offset`，提示淡入用 `AnimatedVisibility`，
    转场透明度用绘制阶段 `graphicsLayer`，拖动时只触发布局与重绘，不重组整页；
    回弹由单次帧时钟动画完成。
