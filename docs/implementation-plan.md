## 实施顺序说明

1. **先做 M0–M3**：数据、解析、分页是阅读器的地基；先以单元测试锁定正确性，避免 UI 返工。
2. **M4–M5 紧随其后**：书架与隐藏书架是入口；隐藏涉及安全，不能留到最后。
3. **M6 阅读器**：分页引擎稳定后再接 UI，减少调试成本。
4. **M7–M10**：打磨、测试、验收与文档。
