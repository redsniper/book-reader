## 2. 测试用例

> 结果栏在测试时填写：`通过 / 失败 / 阻塞`，失败请记录设备、步骤、截图与 logcat。

### BB-01 导入 TXT 并在书架显示

**步骤**
1. 首次启动应用，确认书架为空态。
2. 点击“导入书籍”或右下角“导入”→ 选择 `第一章测试.txt`。
3. 观察书架。

**预期**
- 导入成功后书架出现书籍卡片，显示书名（去除扩展名、书名号与“作者：”后缀）、作者、`TXT` 标识、`已读 0% · 尚未开始`。
- 源 TXT 从 Download 删除后，应用内仍能打开（文件已复制到私有目录）。
- 结果：通过

### BB-02 导入 EPUB 并读取目录

**步骤**
1. 导入 EPUB 并打开。
2. 点击页面中部，再点顶部“目录”。
3. 选择任意靠后的章节。

**预期**
- 目录显示章节数与章节标题，顺序正确；当前章节高亮。
- 点击章节后跳转到该章第一页，顶部/底部栏可正常显示。
- 若 EPUB 有封面，书架卡片显示封面；无封面时显示生成的“纸书”封面。
- 结果：通过

### BB-03 文本 PDF 重排与扫描 PDF 降级

**步骤**
1. 导入文本型 PDF，打开，调整字号。
2. 返回书架，导入扫描版 PDF，打开。

**预期**
- 文本 PDF：显示为可重排文字，字号/行距/主题生效；目录来自提取文字的分章。
- 扫描 PDF：底部或设置面板出现“扫描版 PDF · 保留原始版式”提示；页面按原始版式显示并可按页翻页；字号变化不影响扫描图像本身。
- 结果：通过

### BB-04 多选导入、重复导入与不支持格式

**步骤**
1. 一次选择 TXT + EPUB + PDF 三本书导入。
2. 再次导入同一 TXT。
3. 尝试导入扩展名不支持的文件（如 `.mobi`；若系统选择器不显示，可改名为 `.txt` 导入损坏内容）。

**预期**
- 多选导入逐本完成，书架全部出现；导入过程中有进度提示。
- 重复文件提示“《书名》已在书架中”，书架不新增副本。
- 不支持/损坏文件给出明确失败提示，不产生空书籍，不残留文件。
- 结果：通过

**步骤**
1. 长按（或点击卡片“⋯”）打开书籍编辑。
2. 选择“删除书籍”→ 确认。
3. 重新进入应用。

**预期**
- 书籍从书架消失，阅读进度一并删除。
- 应用私有目录下该书目录被删除（高级验证：

### BB-06 阅读进度自动保存与恢复

**步骤**
1. 打开一本 TXT，翻到第 5 页或滚动到中段。
2. 点击返回回到书架，确认卡片百分比与章节更新。
3. `adb shell am force-stop com.moyue.reader.debug`，重新启动应用并打开同一本书。
4. 再翻到接近末尾，退出重进。

**预期**
- 重进后停留在上次阅读页附近（排版未变时应精确到同一页，误差不超过 1 页）。
- 书架百分比与章节同步更新；读完最后一页显示 100%。
- 结果：通过

### BB-12 下拉进入隐藏书架

**步骤**
1. 未设置密码时，从书架顶部、屏幕上半部起手（如距状态栏约 1/10 屏处）向下缓慢拖动约半屏，观察界面，然后松手。
2. 再次从同一区域向下拖动超过 2/3 屏，保持手指不松开，观察提示与震动；随后松手，按提示去设置密码。
3. 返回后重复步骤 2，输入错误密码；再输入正确密码。
4. 在书架上正常上下滚动（非顶部、短距离下拉），并在下拉途中反向向上滑动。
5. 输入正确密码进入隐藏书架，打开一本隐藏书再返回；旋转屏幕一次。
6. 观察正确密码通过后隐藏书架出现的转场，以及返回/旋转时是否重复播放。

**预期**
- 阈值前（下拉不足整屏 2/3）：书架内容仍跟手阻尼下移、越拉越沉（位移上限约 120dp），顶部留出宣纸空白；**没有锁形圆环、没有“继续下拉”文案、没有震动**。
- 未达 2/3 屏松手：内容弹簧回位，不弹密码框，也不震动。
- 越过 2/3 屏（1080×2400 / 420dpi 模拟器约 1600px）：只轻震一次，顶部淡入朱砂色锁形圆环 + 开锁图标 +“松开进入隐藏书架”；此时仍不弹框，松手后才弹出密码框。
- 提示只在越过阈值后出现；下拉途中反向向上滑动或离开书架顶部，立即撤掉提示并回位。
- 因为阈值是整屏高度的 2/3，必须从屏幕上半部起手：从屏幕中下部开始下拉时，手指会先碰到屏幕边缘，行程不足以到达阈值。这是隐藏入口的预期代价，不是故障。
- 未设置密码：松手后提示先设置密码，可跳转设置页。
- 正确密码：隐藏书架以淡入上浮方式出现，标题显示“隐藏书架”和会话提示。
- 进入转场只在本次解锁后首次呈现时播放；从隐藏书阅读器返回或旋转屏幕不重复播放。
- 错误密码：提示“密码不正确”，不进入。
- 正常滚动/短距离下拉不会误触发，书架内容不会残留位移。
- 结果：模拟器（2026-11-10，Debug 1.1.0）截图核对：累计下拉 800px、1500px 时无任何提示，约 1650–1700px 时提示出现且松手弹出密码框；短距离下拉与反向回弹不弹框。复核基于当日 17:44/17:50 的健康渲染窗口，之后模拟器出现 100% 掉帧、位移帧不刷新的异常。真机 2/3 屏行程、提示震感与手感待用户复核。

- 隐藏/取消隐藏不需要密码；进入隐藏书架需要密码。
- 数据、封面、进度保持不变。
- 结果：通过

4. 清空隐藏书架并重置密码：输入“清空”确认。

### BB-15 隐藏会话与进程安全

**步骤**
1. 进入隐藏书架，打开一本隐藏书，翻到中间某页并记住页码/进度。
2. 按 Home 让应用进入后台，再通过最近任务（Overview）返回。
3. 观察提示；点击“返回书架”，确认隐藏书架已锁定，需要重新下拉并输入密码才能进入。
4. 重新进入隐藏书架并打开同一本书，确认进度仍在。
5. 再次按 Home，改为点击桌面应用图标返回。
6. 在隐藏书阅读中旋转屏幕，观察是否保持当前阅读页。
7. 在阅读器中 `adb shell am force-stop com.moyue.reader.debug`，重新启动应用。

**预期**

## 5. 真机诊断日志与反馈

真机验收时不必每次连 adb：应用会把关键事件写入一份低容量日志，并支持在设置页直接导出。

1. 复现问题后，打开 **设置 → 诊断与反馈**。
2. 点击 **导出诊断日志**，在系统文件选择器中选择“下载”并保存
   （文件名形如 `moyue-diagnostics-20261108-1730.txt`）。
3. 将导出的 `.txt` 与失败记录一起反馈。日志目录同时显示在按钮下方，便于 adb 拉取：
   `adb pull /sdcard/Android/data/com.moyue.reader.debug/files/diagnostics/moyue.log`。

日志包含：设备/系统/屏幕/字体缩放、导入格式与耗时、打开书籍的章节数/字数、分页视口宽高、
字号/行高 px、缓存命中与页数、目标页/字符锚点、跳页/字号变更、进度保存与隐藏会话锁定等
**元数据**；不包含书名、正文、文件路径或密码。单份日志上限约 512 KB（`moyue.log` + `moyue.log.1`），
设置滑块等高频事件会节流，不会持续大量写盘。
