# 墨阅 · 用户黑盒测试指南

> 自动化测试（113 项单元 / Robolectric 集成测试）已全部通过。以下用例需要真实或模拟的 Android 设备完成，因为涉及系统文件选择器、手势、真实 PDF 渲染、沉浸式系统栏与视觉判断，只能由用户执行。

## 1. 测试环境

| 项目 | 要求 |
| --- | --- |
| 设备 | Xiaomi 15 Ultra（HyperOS 3.0.314.0 及以上）优先；或 Android 模拟器 API 35+ |
| 应用 | Debug APK：`app/build/outputs/apk/debug/app-debug.apk` |
| 包名 | `com.moyue.reader.debug` |
| 启动 Activity | `com.moyue.reader.debug/com.moyue.reader.MainActivity` |
| 数据 | TXT、EPUB、文本型 PDF、扫描版 PDF 各准备 1 本；另准备 1 个损坏文件 |

### 1.1 模拟器启动（推荐 Android Studio）

1. 打开 Android Studio → **Device Manager** → **Create Virtual Device**。
2. 选择 **Pixel 8 Pro**（或 Xiaomi 15 Ultra 配置，如有），系统镜像选 **API 35 / Android 15**（API 36 也可）。
3. 启动模拟器。
4. 安装 APK：

```bash
adb install -r app/build/outputs/apk/debug/app-debug.apk
adb shell am start -n com.moyue.reader.debug/com.moyue.reader.MainActivity
```

### 1.2 命令行模拟器（可选）

```bash
sdkmanager "platform-tools" "emulator" "system-images;android-35;google_apis;x86_64"
avdmanager create avd -n moyue_api35 -k "system-images;android-35;google_apis;x86_64" -d pixel_8
emulator -avd moyue_api35
```

### 1.3 推送测试文件

```bash
adb push 第一章测试.txt /sdcard/Download/
adb push 测试书.epub /sdcard/Download/
adb push 文本版.pdf   /sdcard/Download/
adb push 扫描版.pdf   /sdcard/Download/
```

应用内导入时，在系统文件选择器左上角菜单选择 **Downloads**。

### 1.4 测试数据准备建议

- **TXT**：文本中包含 `第一章 初见`、`第二章 再会` 等标题；文件名可写成 `剑来 作者：烽火戏诸侯.txt`，验证书名/作者推断。
- **EPUB**：任意 EPUB 2 或 EPUB 3 小说；可用 Calibre 将 TXT 转为 EPUB。
- **文本型 PDF**：由 Word / WPS / LaTeX 导出的可选中文字的 PDF。
- **扫描版 PDF**：将图片打印为 PDF，或用扫描 App 生成；在电脑上尝试选中文字应无效。
- **损坏文件**：把任意非文本文件改名为 `bad.txt`（或空文件）。

## 2. 测试用例

> 结果栏在测试时填写：`通过 / 失败 / 阻塞`，失败请记录设备、步骤、截图与 logcat。

### BB-01 导入 TXT 并在书架显示

**步骤**
1. 首次启动应用，确认书架为空态。
2. 点击“导入书籍”或右下角“导入”→ 选择 `第一章测试.txt`。
3. 观察书架。

**预期**
- 导入成功后书架出现书籍卡片，显示书名（去除扩展名、书名号与“作者：”后缀）、作者、`TXT` 标识、`已读 0% · 尚未开始`。
- 源 TXT 从 Download 删除后，应用内仍能打开（文件已复制到私有目录）。

### BB-02 导入 EPUB 并读取目录

**步骤**
1. 导入 EPUB 并打开。
2. 点击页面中部，再点顶部“目录”。
3. 选择任意靠后的章节。

**预期**
- 目录显示章节数与章节标题，顺序正确；当前章节高亮。
- 点击章节后跳转到该章第一页，顶部/底部栏可正常显示。
- 若 EPUB 有封面，书架卡片显示封面；无封面时显示生成的“纸书”封面。

### BB-05 删除书籍

**步骤**
1. 长按（或点击卡片“⋯”）打开书籍编辑。
2. 选择“删除书籍”→ 确认。
3. 重新进入应用。

**预期**
- 书籍从书架消失，阅读进度一并删除。
- 应用私有目录下该书目录被删除（高级验证：
  `adb shell run-as com.moyue.reader.debug ls files/books`）。
- 重新启动后仍不存在。

### BB-06 阅读进度自动保存与恢复

**步骤**
1. 打开一本 TXT，翻到第 5 页或滚动到中段。
2. 点击返回回到书架，确认卡片百分比与章节更新。
3. `adb shell am force-stop com.moyue.reader.debug`，重新启动应用并打开同一本书。
4. 再翻到接近末尾，退出重进。

**预期**
- 重进后停留在上次阅读页附近（排版未变时应精确到同一页，误差不超过 1 页）。
- 书架百分比与章节同步更新；读完最后一页显示 100%。

### BB-12 下拉进入隐藏书架

**步骤**
1. 未设置密码时，在书架顶部向下大幅拖动。
2. 按提示去设置密码后返回。
3. 在书架顶部向下大幅拖动，输入错误密码；再输入正确密码。
4. 在书架上正常上下滚动（非顶部、短距离下拉）。

**预期**
- 未设置密码：提示先设置密码，可跳转设置页。
- 正确密码：进入隐藏书架，标题显示“隐藏书架”和会话提示。
- 错误密码：提示“密码不正确”，不进入。
- 正常滚动/短距离下拉不会误触发。
- 结果：__________

### BB-13 隐藏/取消隐藏书籍

**步骤**
1. 在普通书架编辑一本书，选择“隐藏到隐藏书架”。
2. 确认普通书架不再显示它；返回普通书架后下拉并输入密码进入隐藏书架。
3. 在隐藏书架编辑该书，选择“移出隐藏书架”。
4. 退出隐藏书架，确认普通书架恢复显示。

**预期**
- 隐藏后立即从普通书架消失，出现在隐藏书架。
- 隐藏/取消隐藏不需要密码；进入隐藏书架需要密码。
- 数据、封面、进度保持不变。
- 结果：__________

### BB-14 密码设置、修改与忘记重置

**步骤**
1. 设置页 → 隐私与安全 → 设置密码（如 `abcd`）。
2. 修改密码：先输错旧密码，再输入正确旧密码并设置新密码。
3. 使用新密码进入隐藏书架。
4. 清空隐藏书架并重置密码：输入“清空”确认。
5. 验证密码被清除、隐藏书籍消失。
6. **本机哈希验证**：

```bash
adb shell run-as com.moyue.reader.debug cat shared_prefs/hidden_shelf_security.xml
```

**预期**
- 错误旧密码不能修改；两次新密码不一致时保存失败。
- 重置需要输入“清空”，重置后隐藏书籍与文件删除、密码状态变为“未设置”。
- `shared_prefs` 文件中只有 `algorithm / iterations / salt_b64 / hash_b64` 等字段，**没有明文密码**；无法从文件反推出密码。
- 结果：__________

### BB-15 隐藏会话与进程安全

**步骤**
1. 进入隐藏书架，打开一本隐藏书。
2. 按 Home 让应用进入后台，再返回。
3. 在阅读器中 `adb shell am force-stop com.moyue.reader.debug`，重新启动应用。
4. 若系统恢复到阅读器路由，观察提示并返回书架。

**预期**
- 后台返回仍停留在隐藏会话（本次会话有效）。
- 进程被杀后会话失效；不会直接进入隐藏书架；若恢复隐藏书阅读页，应提示“隐藏书架已锁定，请返回书架重新输入密码”。
